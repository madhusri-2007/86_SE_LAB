# Software Engineering Lab

## 📌 About the Repository

This repository contains the **Software Engineering Lab** experiments, assignments, diagrams, and documentation developed as part of the academic coursework.

The lab focuses on understanding and applying software engineering principles, UML modeling, software development processes, and system design techniques.

## 🎯 Objectives

* Understand the fundamentals of Software Engineering.
* Learn different Software Development Life Cycle (SDLC) models.
* Analyze and document software requirements.
* Create UML diagrams for software systems.
* Understand software architecture and system design.
* Apply software engineering concepts to real-world applications.

## 🛠️ Tools Used

* Draw.io / diagrams.net
* StarUML
* Visual Paradigm
* Microsoft Word
* GitHub
